# ADR 0013: License recommendation pending approval

Status: Proposed; owner approval required. Date: 2026-11-26.

## Context

Reference projects use AGPL-3 with differing later-version declarations.

## Alternatives

A permissive companion license cannot be assumed to remove combined-work obligations.

## Decision

Recommend AGPL-3.0-or-later for owner review; do not create an unapproved final license grant.

## Consequences and risks

Public artifacts remain non-releasable until LICENSE, SPDX metadata and attribution are approved. No upstream implementation is copied into product files.

## Reassessment

Reassess before any source copying, bundling, public release or changed linking/integration model.

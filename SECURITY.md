# Security

This unreleased development build has not completed human security review or real
hardware validation. No production security support or supported-release policy is
claimed yet. A private public-project security contact must be approved before release.

Do not disclose credentials or exploitable details in public issues. Report suspected
vulnerabilities through the repository's private vulnerability reporting channel once
that channel is configured and published. Until then, no public reporting destination
is advertised. See [privacy](docs/public/privacy.md) for the trust boundary.

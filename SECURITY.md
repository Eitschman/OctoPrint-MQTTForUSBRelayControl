# Security

Report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/Eitschman/OctoPrint-MQTTForUSBRelayControl/security/advisories/new).
The project maintainer is Eitschman. Private reporting is enabled for this repository.
Do not post exploit details, credentials or configuration dumps in public issues.

Include the affected plugin, Python, OctoPrint and upstream plugin versions, minimal
reproduction steps, expected/actual behavior and a redacted impact description.
Use a disposable environment; do not test an exploit against a printer or unsafe load.
There is no guaranteed response time. No independent security certification is claimed.

Reports about this companion are welcome. Published versions appear on the
[releases page](https://github.com/Eitschman/OctoPrint-MQTTForUSBRelayControl/releases).
Maintenance focuses on the latest published version; update before checking whether
a reported issue still applies.

The owner confirms human review and successful installation and testing on real
hardware. Automated tests use synthetic hardware. The [security review](docs/public/security-review.md)
describes code checks, dependency comparisons and nine unresolved inherited host
advisories. Green companion checks do not certify the host or foreign plugins.
Report an issue in another component to its maintainer using that project's policy.
See [privacy](docs/public/privacy.md) for the trust boundary.

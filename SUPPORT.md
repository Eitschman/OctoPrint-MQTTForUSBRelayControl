# Support

Use the [GitHub issue templates](https://github.com/Eitschman/OctoPrint-MQTTForUSBRelayControl/issues/new/choose)
for bugs, compatibility reports, installation problems and feature requests. Maintainer:
Eitschman. Consult [troubleshooting](docs/public/troubleshooting.md) first.

Include exact Python, OctoPrint, USB Relay Control, MQTT and companion versions,
minimal reproduction steps and expected/actual behavior. Distinguish simulated tests
from observations on real hardware. Never post credentials, complete configurations,
authentication artifacts or private URLs. Security issues belong in the
[private reporting channel](SECURITY.md), not public issues.

The repository is public; published versions appear on the
[releases page](https://github.com/Eitschman/OctoPrint-MQTTForUSBRelayControl/releases).
There is no guaranteed
response time or commercial support agreement. Reviewed fixes, portable tests,
translations and hardware observations can support maintenance. No donation service
is configured.
